# Security

Please report a vulnerability privately, by email to **support@imagestep.dev** with "Security" in the subject line,
not in a public issue. Include what you found, how to reproduce it, and the package and version.

We answer within three working days, keep you informed while we fix it, and credit you when the fix is released,
unless you prefer not to be named.

This covers the packages in this repository and the ImageStep API they call (`api.imagestep.dev`).
